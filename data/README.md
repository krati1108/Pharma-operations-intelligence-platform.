# Synthetic data

The CSV files in `raw/` are generated by `python -m src.data_pipeline`. They model
24 pharmaceutical products, four regional distribution centers, eight suppliers,
104 weeks of product-location demand, batch-level inventory, and purchase orders.

The default simulation uses random seed `42` and business date `2026-09-27`; both can
be changed through the pipeline API. The selected date is stored in SQLite so every
expiry and usable-inventory view uses the same business clock. The data contains no
patient, prescription, or personally identifiable information. All organizations,
products, batches, orders, quantities, and commercial values are fictional.

`pharma_operations.db` and `processed/` are generated locally and ignored by Git.
